### 💻 ২. কম্পিউটারে (PC / VS Code) React অ্যাডমিন রান করার নিয়ম:
১. এই ZIP ফাইলটি আনজিপ করে **VS Code** এ ওপেন করুন।
২. টার্মিনালে ডিপেন্ডেন্সি ইনস্টল করতে কমান্ড দিন:
```bash
npm install
```
৩. লোকাল ডেভেলপমেন্ট সার্ভার চালু করতে:
```bash
npm run dev
```
৪. ব্রাউজারে **http://localhost:3000** ওপেন করলেই অ্যাডমিন ড্যাশবোর্ড চালু হবে।
৫. প্রডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```
*(১০০% কোনো এরর ছাড়াই `dist/` ফোল্ডারে বিল্ড তৈরি হবে)*

---

### 🌐 ৩. Netlify তে ডিপ্লয় করার নিয়ম:
- Build command: `npm run build`
- Publish directory: `dist`
*(প্রজেক্টে ইতিমধ্যে `netlify.toml` ও `public/_redirects` কনফিগার করা আছে)*
