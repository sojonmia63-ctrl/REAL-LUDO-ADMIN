Point 14 • সোর্স কোড ডাউনলোড

📦 সম্পূর্ণ সোর্স কোড ডাউনলোড

পরবর্তীতে যেকোনো পরিবর্তন বা কাস্টমাইজেশনের জন্য আপনার লুডো গেমের ফুল সোর্স কোড (Android অ্যাপ ও অ্যাডমিন প্যানেল) ZIP ফরম্যাটে ডাউনলোড করুন।

📥 আলাদা আলাদা ZIP ডাউনলোড সেন্টার (User & Admin)

📱 Android ফোনে Acode দিয়ে এডিট করার নিয়ম

  1. প্লে স্টোর থেকে Acode - code editor ইনস্টল করুন।
  2. ডাউনলোড করা ZIP ফাইলটি ফোনের ফাইল ম্যানেজার বা ZArchiver দিয়ে আনজিপ করুন।
  3. Acode এ গিয়ে "Open Folder" চাপুন এবং আনজিপ করা ফোল্ডার নির্বাচন করুন।
  4. সমস্ত ফাইল দেখতে পাবেন এবং ইচ্ছেমতো পরিবর্তন করে সেভ করতে পারবেন।

💻 কম্পিউটারে VS Code দিয়ে রান করার নিয়ম

  1. ZIP ফাইলটি আনজিপ করে ফোল্ডারটি VS Code এ ওপেন করুন।
  2. টার্মিনালে কমান্ড দিন: npm install
  3. এরপর রান করতে কমান্ড দিন: npm run dev
  4. ব্রাউজারে http://localhost:3000 চালু করুন।
